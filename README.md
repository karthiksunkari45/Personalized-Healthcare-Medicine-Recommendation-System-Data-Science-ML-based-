# 🏥 Personalized Healthcare & Medicine Recommendation System

## 📌 Project Overview

**Personalized Healthcare & Medicine Recommendation System** is a Data Science and Machine Learning project designed to analyze healthcare-related patient data and generate medicine recommendations using a trained machine learning model.

The project demonstrates an end-to-end machine learning workflow, starting from a cleaned healthcare dataset and ending with model-based predictions and an interactive Power BI dashboard.

> ⚠️ **Disclaimer:** This project is developed for educational and portfolio purposes. The predictions generated by the model should not be considered medical advice, diagnosis, or a substitute for consultation with a qualified healthcare professional.

---

## 🎯 Project Objectives

* Analyze healthcare and patient-related data.
* Perform data preprocessing and validation.
* Identify relationships between patient characteristics, medical conditions, and medicines.
* Apply Machine Learning for medicine recommendation.
* Use the trained model to generate predictions.
* Visualize healthcare insights through a Power BI dashboard.
* Demonstrate an end-to-end Data Science project workflow.

# 📂 Project Files

The main files used in this project are:

### `Cleaned_Dataset.csv`

This is the cleaned healthcare dataset used for analysis and machine-learning prediction.

It represents the processed version of the original dataset after data-cleaning and preparation steps.

The dataset can be used for:

* Patient analysis
* Medical condition analysis
* Medicine analysis
* Exploratory Data Analysis
* Model input
* Power BI visualization

### `best_model.pkl`

This is the saved Machine Learning model selected as the project's final/best model.

The `.pkl` file allows the trained model to be loaded without retraining it every time.

Example:

```python
import joblib

model = joblib.load("best_model.pkl")
```

The model can then be used to generate predictions using data prepared with the same feature structure used during training.

# 🔮 Prediction

The saved model can be loaded using Joblib:

```python
import joblib

model = joblib.load("best_model.pkl")
```

After loading the model, input data must be prepared using the **same preprocessing and feature structure used during model training**.

Example:

```python
prediction = model.predict(X_new)

print(prediction)
```

> **Important:** Do not manually change, remove, or reorder model features unless they match the original training pipeline.
